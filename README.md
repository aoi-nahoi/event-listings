# Event Listings

## Project Overview

This project is a web application that allows users to create, browse, and search for local events.

## Development Environment

- Python 3.10
- uv
- Git

## Tools

- Black (code formatter)
- Ruff (linter)
- pytest (testing)
- pytest-cov (test coverage)

## Setup

Create the virtual environment:

```bash
uv venv
```

Activate it:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
uv pip install black ruff pytest pytest-cov
```
